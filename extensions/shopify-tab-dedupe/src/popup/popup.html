TabEase
No Shopify tabs open. Open a store's preview, theme editor, code editor or admin; each gets one tab, and new links reuse it.

Tab groups

Patterns match a store, domain or URL path, comma-separated. * is a wildcard: redwolf*, tagmanager.google.com. Rename or recolour a group in Chrome's tab strip and TabEase keeps it that way.

Need two tabs anyway? Right-click a link → Open link in new tab (keep separate).
