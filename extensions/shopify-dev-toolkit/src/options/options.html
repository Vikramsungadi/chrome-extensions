Settings

Settings sync through your Chrome profile.

General

Used by the section inspector's “Local” button.

Linked stores

For setups with a separate Shopify store per region (e.g. India, UAE, US). The popup opens the same page on each one.

Local repositories

Theme repo path per store, keyed by myshopify domain.

Theme access

Lets the section inspector read your theme's JSON templates (through your signed-in admin session or an Admin API token) to show each section's real file. Only requested Shopify domains are accessed: *.myshopify.com and admin.shopify.com.

Admin API tokens

Optional. Lets the section inspector read theme JSON to find each section's real type. Needs the read_themes scope. Without a token it tries your signed-in admin session. Stored on this machine only, not synced.
